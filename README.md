# sn00py — spacehey profile

A standalone, static recreation of my [SpaceHey](https://spacehey.com) profile,
rebuilt as a plain HTML/CSS site so it can be hosted anywhere (e.g. GitHub Pages).

## Files

- `index.html` — the profile page
- `style.css` — all styling (the original profile theme)
- `avatar.png` — profile picture (place in the same folder)
- `README.md` — this file

## Usage

Just open `index.html` in a browser, or serve the folder with any static
web server. No build step, no dependencies.

For GitHub Pages: push this folder to a repository and enable Pages on the
default branch / root.

## Sections

The page mirrors the SpaceHey profile layout: profile picture, contact and
url boxes, an interests table (General, Music, Movies, Television, Books,
Heroes), the full "About me" blurb (with the custom sn00py terminal theme),
and "Who I'd like to meet".
